This note introduces a preliminary computational framework for reconstructing a permutation matrix from partially observed row and column statistics. The hidden object is an ($n\times n$) matrix containing each integer from (1) through ($n^{2}$) exactly once. For every row and column, two statistics are defined: the sum of its' entries and the sum of the logarithms of its' entries. Only a random subset of these statistics is observed. The reconstruction problem is reformulated away from regression and towards a direct search approach. The initial model, called \textbf{Simple Swap}, maintains two independently initialized permutation hypotheses. One hypothesis attempts to satisfy the observed row statistics, while the other attempts to satisfy the observed column statistics. Each hypothesis is modified separately through simple pairwise swaps. The central mechanism is a simulated-annealing procedure that introduces a time-dependent compatibility measure between the two hypotheses. At each iteration, the relative row and column reconstruction errors influence which hypothesis receives the next proposed move. The intention is to allow each marginal representation to make progress independently while progressively encouraging the two representations to become compatible descriptions of the same permutation. A Graph Neural Network (GNN) is used to propose swaps and GNN implementation is done using PyTorch. The initial implementation fixes ($n=4$), giving a permutation of ($1,\ldots,16$). This deliberately simple setting is intended to test the underlying search principle before more sophisticated move operators, compatibility measures, and learned search mechanisms are introduced.
